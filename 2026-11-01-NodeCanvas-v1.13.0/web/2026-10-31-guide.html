01 · 시작하기

무엇을 준비하면 되나요?

NodeCanvas는 브라우저에서 작업하고, Windows 연결 앱을 통해 내 ChatGPT 계정으로 이미지 생성을 요청하는 도구입니다.

  • Windows 10/11 x64 PC와 인터넷 연결
  • 이미지 생성 기능을 사용할 수 있는 ChatGPT 계정
  • 처음 한 번 설치하는 NodeCanvas 연결 앱
프로젝트 편집과 설명서 열람에는 로그인이 필요 없습니다. 실제 이미지 생성 가능 여부와 사용 한도는 계정·구독·Codex 버전에 따라 달라집니다.
02 · AI 연결

PC 연결과 계정 로그인은 달라요.

PC 연결은 작업실과 내 컴퓨터 사이의 통로를 여는 단계, 계정 로그인은 그 통로에서 사용할 내 ChatGPT 계정을 인증하는 단계입니다.

1

작업실과 내 PC 연결하기

작업실에서 AI 연결을 엽니다. 처음이면 설치 앱 다운로드로 받은 파일을 실행해 설치하세요. 이미 설치했다면 다시 설치할 필요가 없습니다.

PC 연결하기를 누르고, 브라우저가 물으면 앱 열기를 허용합니다. 연결 앱에서 작업실 주소를 확인합니다.

완료 표시: ✓ PC 연결 완료

이 표시는 PC 연결만 끝났다는 뜻입니다. 아직 계정 로그인 전일 수 있어요.

2

공식 페이지에서 내 계정 로그인하기

PC 연결 후 로그인 시작하기를 누릅니다. 이어서 나타나는 검은색 공식 페이지에서 로그인하기 ↗를 누르세요.

새로 열린 공식 페이지에서 직접 로그인합니다. 필요한 계정 선택과 인증을 완료하세요.

공식 페이지를 여는 것만으로 로그인이 끝나지는 않습니다. 해당 페이지 안에서 인증을 끝내야 합니다.
3

이 작업실로 돌아오기

인증을 끝낸 뒤 원래 작업실 탭으로 돌아오세요. 완료 여부를 자동으로 확인합니다.

완료 표시: ChatGPT 연결됨

이제 연결창을 닫고 이미지를 만들 수 있습니다. 바로 바뀌지 않으면 고급 연결의 상태 다시 확인을 누르세요.

‘링크 다시 받기’는 언제 누르나요?

공식 페이지가 열리지 않거나 링크가 만료됐을 때만 사용합니다. 이미 공식 페이지에서 로그인 중이라면 그대로 완료하세요. 새 링크를 받으면 앞서 열었던 로그인 요청이 바뀔 수 있습니다.

‘이 PC에서 로그인 유지’는 무엇인가요?

선택하면 연결 앱이 OS 자격 증명 저장소를 사용해 다음 실행에도 로그인을 유지하도록 합니다. 개인 PC에서만 선택하세요. 선택하지 않으면 임시 로그인으로 사용하며 연결 앱 종료 후 다시 로그인해야 합니다. 로그인 요청 중에는 선택을 바꿀 수 없습니다.

03 · 첫 이미지

노드 하나로 시작하세요.

  1. 프로젝트 목록에서 새 프로젝트를 만듭니다.
  2. 빈 캔버스를 우클릭하거나 ＋를 눌러 이미지 생성기를 추가합니다.
  3. 노드 안 프롬프트 칸에 원하는 장면을 적습니다.
  4. ChatGPT 연결됨을 확인하고 전체 실행을 누릅니다.
  5. 생성이 끝나면 노드에서 이미지를 확인하고 저장합니다.
프롬프트 예시

따뜻한 아침 햇빛이 드는 창가의 작은 꽃병. 흰 배경, 부드러운 그림자, 정사각형 제품 사진.

실행은 구독 사용 한도를 사용할 수 있습니다. 반복 실행하면 생성·편집 노드가 다시 실행될 수 있으니 필요한 작업만 실행하세요.
04 · 노드

각 노드는 무슨 일을 하나요?

노드 제목 옆 ?에서도 역할과 연결 예시를 볼 수 있습니다. 텍스트는 지시문, 이미지는 작업 재료입니다.

T

텍스트

지시문을 재사용하거나 여러 카드에 공유할 때 선택적으로 사용합니다. 생성·편집 카드 안에 직접 입력하면 별도 텍스트 노드는 필요 없습니다.

입력: 글 직접 입력
출력: 텍스트
↥

이미지 업로드

PC의 PNG·JPG·WebP를 가져옵니다. 카드를 짧게 클릭하면 선택창, 누른 채 끌면 노드 이동입니다.

입력: 내 이미지 파일
출력: 이미지
✦

이미지 생성기

지시문과 선택 사항인 참조 이미지를 바탕으로 새 이미지를 만듭니다. 노드 안에 바로 지시문을 적어도 됩니다.

입력: 텍스트 · 참조 이미지(선택)
출력: 새로 생성한 이미지
◈

이미지 편집기

연결된 이미지에서 바꿀 부분과 유지할 부분을 지시합니다. 편집할 이미지가 최소 한 장 필요합니다.

입력: 이미지 + 편집 지시문
출력: 편집한 이미지

시작 템플릿은 어떻게 쓰나요?

이미지 만들기는 생성기 하나로 시작합니다. 카드 안의 예시 프롬프트를 원하는 내용으로 바꾸세요. 이미지 편집하기는 업로드와 편집기 두 카드입니다. 업로드 카드에서 파일을 선택하고 편집기 안의 예시 편집 지시를 수정하세요. 예시 문구는 실행 결과가 아니며, 실행 전 자유롭게 바꿀 수 있습니다.

텍스트 노드를 연결하면 어디에 입력하나요?

텍스트 노드가 연결되면 연결된 텍스트 사용 중과 원본 이름이 표시됩니다. 이름을 누르면 원본 텍스트를 편집할 수 있습니다. 생성·편집 카드의 추가 지시사항 (선택)에는 덧붙일 내용만 적으세요. 연결된 텍스트와 추가 지시사항을 함께 전달합니다. 연결을 해제하면 입력칸은 다시 기본 프롬프트 또는 편집 지시로 바뀌며 직접 입력한 내용은 유지됩니다. 연결된 텍스트가 비어 있으면 내용 없음으로 안내합니다.

이미지 크기와 입력 테두리

이미지를 불러오거나 생성하면 카드 너비는 유지하고 이미지 높이를 실제 비율에 맞춥니다. 가로·세로 이미지를 자르거나 늘리지 않습니다. 다른 곳을 클릭하면 입력 초점 테두리가 해제되며, 키보드로 이동할 때의 초점 표시는 유지됩니다.

생성한 이미지는 어디에서 저장하나요?

생성·편집 카드에서 바로 확인하고 저장합니다. 노드를 선택하면 카드 주변에 저장 아이콘이 나타납니다. 저장 버튼은 이미지를 내려받으며 AI를 다시 실행하지 않습니다.

생성기 안에 프롬프트 입력 → 생성·저장
이미지 업로드→편집기 안에 지시 입력 → 편집·저장

노드 오른쪽 출력 포트를 잡고 다음 노드 왼쪽 입력 포트까지 끌어 연결합니다. 순환 연결과 호환되지 않는 연결은 만들 수 없습니다.

스킬을 연결해 새 결과 만들기

스킬은 이미지 제작에 사용할 지침을 담은 노드입니다. 목록에서 원하는 스킬을 선택하고 생성·편집 노드에 연결하면 실행할 때 지침이 함께 적용됩니다.

  1. 빈 캔버스에서 우클릭하고 스킬을 선택합니다.
  2. 목록에서 사용할 스킬을 선택합니다. 추가된 노드의 이름과 짧은 설명으로 용도를 확인하세요.
  3. 스킬 노드 오른쪽의 퍼즐 출력을 다음 이미지 생성·편집 노드의 퍼즐 스킬 입력에 끌어 연결합니다.
  4. 선택한 스킬에 원본 이미지가 필요하면, 기존 이미지의 출력을 같은 생성·편집 노드의 이미지 입력에 연결합니다.
  5. 원하는 변경 내용을 다음 노드 안에 적고, 그 노드의 생성하기 또는 편집하기를 누릅니다.

생성용과 편집용 스킬

목록과 노드 설명의 ‘생성용’·‘편집용’ 표시를 확인하세요. 생성용 스킬은 캐릭터나 장면 설명만으로 새 이미지를 만들며 원본 사진은 필수가 아닙니다. 이미지 생성 노드에 연결해 원하는 외모·의상·장면을 적습니다. 편집용 스킬은 기존 사진을 바꾸므로 원본 이미지를 생성·편집 노드의 이미지 입력에 연결하고 변경할 내용을 적습니다.

스킬에 화면비 조건이 있으면 해당 비율을 자동 적용하며 비율 선택은 잠깁니다. 가로형 스킬은 지원되는 가로 비율을 사용합니다. 정확한 패널 수나 구도는 생성 결과에서 직접 확인하세요. 연결 가능한 스킬 목록은 입력 노드에 맞춰 표시됩니다.

원본과 새 결과

연결만으로 이미지는 바뀌지 않습니다. 다음 노드의 선택 실행은 이미 완성된 앞쪽 AI 이미지를 재사용하고 새 결과를 실행한 노드에 저장합니다. 선택한 노드 자체는 새로 실행합니다. 앞쪽 이미지가 아직 없으면 필요한 앞 노드부터 실행합니다.

전체 실행은 앞쪽 노드의 결과도 다시 만들 수 있습니다. 기존 이미지를 유지하려면 다음 노드 안의 실행 버튼을 사용하세요. 앞쪽 지시를 바꾼 내용을 반영하려면 그 노드를 먼저 직접 실행한 뒤 다음 노드를 실행합니다.

연결과 해제

  • 생성·편집 노드 하나에는 스킬 하나만 연결합니다.
  • 같은 스킬 노드를 여러 생성·편집 노드가 공유할 수 있습니다. 서로 다른 결과가 필요하면 다음 노드를 나누어 지시를 각각 입력합니다.
  • 스킬 연결을 끊거나 스킬 노드를 삭제하면 적용이 해제됩니다.
  • 텍스트·이미지·스킬은 각각 맞는 입력 아이콘에 연결합니다. 아이콘에 마우스를 올리거나 키보드로 초점을 맞추면 설명을 볼 수 있습니다.

실행 전 확인

선택한 스킬에 필요한 이미지와 지시를 준비하세요. 스킬 지침과 연결된 텍스트·직접 입력한 지시의 합계는 16,000자까지 지원합니다. 초과하면 지시를 줄여야 하며 스킬 지침은 임의로 자르지 않습니다. 스킬 노드 자체는 이미지를 생성하지 않습니다.

스킬 지침은 이미지 생성을 실행할 때 AI 서비스에 함께 전달됩니다. 앱의 자동 품질 검수·재시도는 제공하지 않으므로 결과는 직접 확인하세요. 저장·JSON 백업·실행 취소에는 스킬 선택과 연결이 유지됩니다.

목록에 원하는 스킬이 보이지 않으면 작업실을 새로고침하고, 해당 작업실에 등록된 스킬인지 확인하세요. 파일 업로드나 원문 보기 기능은 사용하지 않습니다. 이전 버전으로 돌아갈 계획이라면 업데이트 전 프로젝트 JSON도 별도로 보관하세요.

노드 주변의 작은 도구
노드를 선택하거나 마우스를 올리면 저장·복제·삭제 도구가 나타납니다. 포트 이름과 설명은 해당 아이콘에 마우스를 올리거나 키보드 초점을 줄 때만 표시됩니다. 키보드 Tab으로도 이동할 수 있습니다. 저장은 이미지를 내려받으며 AI를 다시 실행하지 않습니다. 연결을 시작하면 자료형이 맞는 포트가 강조됩니다. 맞지 않는 포트에는 선이 연결되지 않습니다.
05 · 조작

클릭은 입력, 드래그는 이동.

노드 추가 메뉴는 전체 · 이미지 · 텍스트로 골라 볼 수 있습니다. 이미지 업로드·이미지 생성기·이미지 편집기·텍스트를 하나의 목록에서 선택하세요. 각 항목 아래의 짧은 설명으로 역할을 구분하고, 검색창에서 이름이나 기능으로 찾을 수 있습니다.

노드 추가
빈 캔버스 우클릭 / ＋ / Shift+F10
노드 이동
카드 여백·이미지·제목 영역을 잡고 끌기. 선택된 노드를 끌면 선택한 노드가 함께 이동합니다. 입력칸은 편집용입니다.
다중 선택
선택 도구에서 빈 캔버스를 왼쪽 드래그하면 선택 상자와 겹치는 노드가 선택됩니다. Ctrl+클릭(Mac은 Command+클릭)으로 추가·해제합니다. 빈 공간 클릭 또는 Esc로 선택을 해제합니다.
연결선 만들기
오른쪽 출력 아이콘 → 왼쪽 입력 아이콘으로 드래그합니다. T는 텍스트·프롬프트, ▧는 이미지입니다. 생성·편집 노드는 두 입력이 분리돼 있습니다. 빈 곳에 놓으면 해당 포트에 맞는 노드를 고릅니다.
화면 이동
Space를 누른 채 왼쪽 드래그하거나 H로 이동 도구를 선택합니다. V는 선택 도구입니다. 입력칸에서는 Space가 글 입력으로 동작합니다.
확대·축소
마우스 휠 또는 화면 아래 − / +. 전체 노드 보기는 맞춤 보기 버튼.
취소·삭제
Esc: 연결 취소·선택 해제 / Delete: 마지막으로 선택한 노드 삭제
실행 취소·다시 실행
Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y. 입력칸에서는 글 편집 취소가 먼저 적용됩니다.
06 · 보관

저장과 사용량을 구분하세요.

현재 프로젝트의 제한과 사전 경고

작업실 오른쪽 위 현재 프로젝트에서 노드·연결·용량 사용량과 최대치를 확인합니다. 눌러 펼치면 자세한 기준을 볼 수 있습니다. 프로젝트 하나에 노드 150개 · 연결 500개 · 이미지 포함 용량 200MB까지 지원합니다.

80%인 노드 120개 · 연결 400개 · 용량 160MB부터 미리 안내합니다. 경고는 사용량 옆에 유지되며 입력할 때마다 팝업으로 반복하지 않습니다. 불필요한 노드나 연결·이미지를 정리해 기준 아래로 내려가면 해제됩니다. 최대치에 도달하거나 초과한 상태는 별도로 표시합니다. 프로젝트 용량이 200MB를 넘으면 용량을 줄여야 다시 저장할 수 있습니다.

프로젝트 용량은 저장·JSON 백업과 같은 프로젝트 데이터 기준입니다. 같은 이미지가 여러 카드에 있으면 각 카드의 이미지 데이터를 계산하므로, 브라우저가 이미지를 중복 제거해 보관한 실제 점유량과 다를 수 있습니다.

프로젝트 목록의 사이트 전체 저장량

이 사이트 전체 저장량은 현재 브라우저 프로필의 이 사이트에 저장한 전체 프로젝트·휴지통 등 데이터의 추정치입니다. 다른 사이트·다른 브라우저·다른 PC의 데이터를 합산하지 않습니다. 브라우저 허용량은 브라우저가 제공하는 예상 한도이며 전용으로 확보한 공간이 아니고 달라질 수 있습니다. 프로젝트 하나의 200MB 제한과는 별개입니다. MB·GB로 표시하며 브라우저가 일부 정보를 제공하지 않으면 해당 값만 ‘확인 불가’로 표시합니다.

자동 저장과 파일 백업

자동 저장은 현재 브라우저에 프로젝트를 보관합니다. 계정으로 다른 PC에 동기화되는 기능은 아닙니다. 브라우저 데이터 삭제 시 작업도 사라질 수 있습니다.

저장 ↗ 또는 Ctrl+S는 프로젝트를 JSON 파일로 내려받는 백업입니다. 이미지를 포함하며 현재 저장·가져오기 공통 제한은 200MB입니다. 프로젝트 목록의 가져오기로 백업을 다시 엽니다. 이미지 저장은 결과 이미지만 내려받습니다.

  • 프로젝트 목록에서 이름 변경, 복제, 휴지통 이동과 복원을 할 수 있습니다.
  • 영구 삭제는 휴지통에서만 합니다. 백업 후 ‘삭제’를 입력해 확인하면 되돌릴 수 없습니다.
  • 저장 실패 시 저장 재시도를 누릅니다. 다른 탭에서 수정해 충돌했다면 현재 작업을 JSON으로 백업하고 새로고침하세요.
07 · 문제 해결

여기서 막혔나요?

‘PC 연결 완료 · 로그인해 주세요’가 보여요.

PC 연결만 완료됐습니다. 2번에서 로그인 시작하기 → 공식 페이지에서 로그인하기를 누르고 계정 인증까지 완료하세요.

로그인했는데 작업실이 대기 중이에요.

원래 작업실 탭으로 돌아온 뒤 잠시 기다리세요. 고급 연결 → 상태 다시 확인을 눌러 확인합니다. 공식 페이지에서 인증이 끝났는지도 확인하세요. 링크 만료 안내가 있으면 링크를 다시 받아 최신 페이지에서 진행합니다.

‘7330 포트를 사용 중’이라고 나와요.

이전에 실행한 연결 앱이나 개발용 서버가 남아 있을 수 있습니다. 기존 연결 앱을 종료한 뒤 PC 연결하기를 다시 누르세요. 다른 프로그램이 해당 포트를 사용하는 경우에는 그 프로그램을 확인해야 합니다. 재설치만으로 포트 충돌이 해결되지는 않습니다.

연결하기를 눌러도 앱이 열리지 않아요.

연결 앱을 먼저 설치했는지 확인하고 브라우저의 ‘앱 열기’ 요청을 허용하세요. 연결 앱에서 작업실 주소가 현재 사이트와 같은지 확인합니다. 자동 연결이 안 되면 고급 연결의 연결 코드 입력을 사용합니다. 브라우저가 로컬 네트워크 권한을 물으면 연결 앱 접근을 허용하세요.

노드가 움직이지 않거나 연결이 안 돼요.

선택 도구(V)인지 확인하고 입력칸·버튼 대신 카드 여백이나 이미지를 잡으세요. 연결은 출력 점에서 입력 점으로 끕니다. 입력칸은 글 편집용이며, 모든 포트 조합이 연결되는 것은 아닙니다.

이미지 생성이 실패했어요.

ChatGPT 연결됨 상태, 인터넷 연결, 오류 안내와 계정 사용 한도를 확인하세요. 이미지 편집에는 입력 이미지가 필요합니다. 이미지를 만들려면 생성 또는 편집 노드를 실행해야 합니다.

연결 앱 업데이트

최초 한 번 v1.13.0 이상을 설치하면 연결 앱이 실행될 때, 작업실에 새로 연결할 때와 약 6시간마다 새 버전을 자동 확인하고 다운로드합니다. AI 연결 창에 준비 완료가 표시되면 ‘지금 적용’을 누르세요. 생성·로그인 중에는 적용할 수 없습니다.

앱을 재시작한 뒤 현재 작업실을 자동으로 다시 연결합니다. 브라우저 프로젝트와 로그인 유지 설정은 보존합니다. 로그인 유지를 선택하지 않았다면 ChatGPT에 다시 로그인하세요. 인터넷이나 다운로드 검증에 실패하면 기존 앱을 계속 사용할 수 있습니다.

기존 v1.8.2 이하에는 업데이트 기능이 없으므로 이번 한 번은 새 설치 파일을 직접 실행해야 합니다. 업데이트 적용 후에도 연결되지 않으면 PC 연결하기를 다시 누르세요.

이미지 생성 시간 확인

생성 중에는 현재 상태와 경과 초가 표시됩니다. 완성된 이미지가 도착하면 Codex 응답이 끝나기 전에도 노드에 먼저 표시됩니다. 응답 정리 중에는 다음 실행을 기다려 주세요.

하단 실행 기록의 ‘단계별 시간’을 펼치면 해당 노드 요청 이후 각 이벤트까지 걸린 누적 시간을 확인할 수 있습니다. 생성 시작 이벤트가 제공되지 않으면 해당 항목은 나타나지 않습니다. 기록은 이 탭에서만 유지되며 새로고침하면 사라집니다. 중간 생성 미리보기는 제공하지 않습니다.

실제 이미지 생성 시간은 서비스 상황과 요청에 따라 달라집니다. 이 기능이 생성 모델 자체를 빠르게 만드는 것은 아닙니다.

08 · 연결 정보

무엇이 어디에 보관되나요?

프로젝트는 브라우저에 저장됩니다. ChatGPT 인증 토큰은 웹이나 Vercel에 저장하지 않으며 연결 앱이 처리합니다. 이미지 생성을 실행하면 입력 지시문과 필요한 이미지가 연결 앱을 통해 AI 서비스로 전달됩니다.

‘이 브라우저에서 PC 연결 기억하기’는 작업실과 연결 앱 사이의 연결 정보를 기억하는 설정입니다. ‘이 PC에서 로그인 유지’는 ChatGPT 계정 인증을 유지하는 설정으로 서로 다릅니다.

마지막 작업실 연결 탭을 닫으면 약 90초 뒤 연결 앱이 종료됩니다. 이 설명서 탭은 AI 연결을 유지하지 않습니다. 설명서만 열어둔 채 작업실을 모두 닫으면 다시 연결해야 할 수 있습니다.
