    MY AI CONNECTION

    내 ChatGPT로 이미지 만들기

    먼저 PC를 연결하고, 공식 페이지에서 내 ChatGPT 계정으로 로그인하세요. PC 연결과 계정 로그인은 서로 다른 단계예요.

    1

    작업실과 내 PC 연결하기

    PC 연결 필요

    이미지를 만들 때 필요한 연결 앱을 PC에서 실행하는 단계입니다. 처음 한 번 설치하고, 다음부터는 ‘PC 연결하기’를 누르세요.

    설치 앱 다운로드 ↗
    연결 앱 업데이트

    업데이트 확인 중

    확인과 다운로드는 자동으로 진행합니다. 적용하면 연결 앱이 재시작됩니다. 임시 로그인은 다시 필요할 수 있어요.

    설치 후 ‘연결하기’를 누르세요. 브라우저가 물으면 앱 열기를 허용하세요.

    2

    공식 페이지에서 계정 로그인하기

    먼저 1번에서 PC를 연결하세요. 연결이 끝나면 로그인할 수 있어요.

    공식 페이지에서 로그인하기 ↗

    ① 위 버튼으로 공식 페이지 열기 → ② 계정 로그인 완료 → ③ 이 작업실로 돌아오기. ‘ChatGPT 연결됨’으로 바뀌면 이미지를 만들 수 있어요. 이미 로그인 중이라면 링크를 새로 받을 필요가 없어요.

    로그인 유지: 개인 PC에서만 선택하세요. 선택하지 않으면 연결 앱이 종료될 때 다시 로그인이 필요합니다.

    연결 앱을 설치했나요? 연결하기를 눌러 주세요.

    마지막 작업실 탭을 닫으면 약 90초 뒤 연결 앱도 종료됩니다. 로그인 유지를 선택하지 않으면 임시 로그인도 해제됩니다.

    A QUICK START

    생각을 이미지로 잇는 방법

    전체 사용 설명서 보기 ↗

    1. 우클릭으로 노드를 추가해요.

      빈 캔버스에서 우클릭하거나 왼쪽 + 버튼을 누르세요. 이미지 파일을 끌어 놓아 업로드 노드를 바로 만들 수도 있어요. 같은 종류의 노드는 이름 뒤 #번호로 구분해요.

    2. 장면을 적어요.

      노드 안의 입력칸에 프롬프트를 바로 입력하세요.

    3. 카드를 잡고 이동해요.

      노드의 이미지나 카드 여백을 끌어 원하는 곳에 놓으세요. 빈 공간 드래그로 여러 노드를 선택한 뒤 함께 옮길 수 있어요. Space를 누른 채 드래그하면 화면이 이동해요. 입력칸은 바로 편집할 수 있어요.

    4. 노드를 연결해요.

      오른쪽 출력 아이콘을 잡고 왼쪽 입력 아이콘까지 끌어 놓으세요. T는 프롬프트, ▧는 이미지입니다. 빈 곳에 놓으면 호환 노드를 추가할 수 있어요.

    5. 내 AI와 연결해요.

      AI 연결에서 로컬 앱을 페어링하고 ChatGPT에 로그인하세요.

    6. 워크플로를 실행해요.

      연결 순서대로 이미지를 생성합니다. 선택 실행은 완성된 앞쪽 이미지를 재사용하고 선택한 노드를 새로 실행합니다. 앞쪽에 이미지가 없으면 필요한 노드부터 실행합니다. 전체 실행은 앞쪽 결과도 다시 만듭니다. 실행마다 구독 한도를 사용할 수 있어요. 생성 중에도 다른 노드·프로젝트를 편집할 수 있고, 추가 요청은 순서대로 생성해요. 노드 중앙 진행 표시와 오른쪽 아래 작업 목록에서 상태를 확인하세요. 작업 중에는 탭을 닫거나 새로고침하지 마세요.

    Space + 드래그 / H 화면 이동빈 캔버스 드래그 다중 선택Ctrl / ⌘ + 클릭 추가 선택·해제마우스 휠 확대·축소Esc 연결 취소·선택 해제Delete 마지막 선택 노드 삭제Ctrl / ⌘ + S JSON 백업

    오른쪽 위 ‘현재 프로젝트’에서 사용량을 확인하세요. 노드 120개·연결 400개·용량 160MB부터 미리 안내하며, 프로젝트별 최대치는 150개·500개·200MB입니다.

    자동 저장은 이 브라우저에만 보관됩니다. 중요한 작업은 프로젝트 저장으로 백업하세요. 실제 이미지 생성 가능 여부는 계정과 Codex 버전에 따라 달라집니다.
