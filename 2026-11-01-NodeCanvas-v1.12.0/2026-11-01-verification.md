# NodeCanvas v1.12.0 검증 — 2026-11-01

- 기존 v1.11.0 및 sample, 루트 문서/설정 보존. 새 버전만 변경.
- 생성 노드에 스킬 전용 입력 허용. 편집 노드도 계속 지원.
- HairLock은 원본 이미지 필수. 생성 노드에 연결해도 job.kind=edit로 원문 및 참조 전달. 스킬 없으면 기존 생성 요청.
- 선택 실행은 완성된 상위 AI 결과를 재사용하고, 선택한 노드 자체는 새로 실행. 전체 실행은 기존 전체 재실행 정책 유지.
- 소스 이미지/지시문과 결과 저장 위치, 원문 SHA256 보존.

## 검증
- 100/100 Node 단위·통합 테스트 PASS.
- 기존 스킬 노드 브라우저 흐름 PASS.
- 생성 노드 브라우저 흐름 PASS: 실제 포트 드래그, 원본 이미지+HairLock 전달, 요청 1회, 이전 AI 노드 이미지/지시 완전 불변, 다음 노드에만 새 결과 저장, 재접속, 이미지 누락 시 요청 전 중단, 스킬 해제 후 generate 요청, 모바일 원문 보기, JS pageerror 없음.
- AI 응답은 모의. 실제 생성 품질·계정 및 설치 PC/HTTPS 업데이트 전체는 미검증.
- 설치 빌드/self-test·서명·ZIP 무결성 검증은 배포 안내에 기록.
- 자체 평가 8.5/10. 공개 배포 및 PC 설치는 수행하지 않음.
