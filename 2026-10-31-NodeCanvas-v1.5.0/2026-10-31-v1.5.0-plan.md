# NodeCanvas v1.5.0 승인 보완 계획

승인: 자체점검의 4개 결함과 추가 개선을 모두 보완하고 10점을 목표로 검증. 이전 버전/sample/외부 파일 보존. root 기본 4문서는 이미 존재하며 최종 결과로 갱신한다.

T1 저장: 내부 객체 복원은 100MB JSON 제한과 분리하되 JSON 입출력/저장은 동일한 공통 제한과 용량 사전 검사를 적용. 기존 100MB 초과 저장본은 내부에서 열고 이미지 분리 저장으로 복구. IndexedDB v2 메타/축소미리보기, 프로젝트 본문, 이미지 Blob 별도 저장. atomic 저장/이전. 목록은 원본 이미지 getAll 사용 금지. 저장공간 표시, 재시도, 버전 충돌 감지, 백업 가능한 휴지통의 선택 영구삭제.
T2 연결: initialize 실패/timeout/재시도에서 소유 프로세스/이벤트 정리. 참조 임시 파일은 성공/실패/취소 후 정리하고 남은 이전 작업도 시작 시 안전하게 정리. 모의 실패/정상 이미지 경로 테스트.
T3 설치: 기존 런타임 무결성 검사/명시적 복구 설치. 단계별 스테이징/백업/오류 시 롤백 및 원본 복원. 파일 잠김/누락/손상/동일 버전 재실행 테스트. 실제 AppData/레지스트리 설치는 하지 않는다. 코드 서명/실계정 같은 외부 조건은 완료로 가장하지 않는다.
T4 편집: 메모리 제한이 있는 Undo/Redo(텍스트 그룹화/이동/연결/노드/업로드), 키보드 및 터치 기본 검증. 저장 실패 재시도와 화면전환 보호.
T5 검증: 작업별 별도 검토, 통합 4개 결함 재현 회귀, 실제 브라우저 저장/삭제확인/UndoRedo/업로드, 새 payload/EXE/ZIP, 모든 파일 목록/문서. 실제 공개 HTTPS·신규PC·계정 로그인/생성은 수행 여부를 정확히 구분하고 점수를 증거로 평가.
