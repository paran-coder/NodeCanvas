# NodeCanvas v1.8.2 — 2026-11-01

## 변경 범위
- v1.8.1 보존, 새 v1.8.2 생성.
- 유효한 이미지 완성 이벤트를 수신하면 전체 turn 완료 전에도 노드에 표시·저장. turn 완료까지 동시 생성 제한 및 취소/오류 처리 유지.
- 연결·계정 확인, 요청 전송, 생성 시작(제공 시), 이미지 수신, Codex 응답 완료의 누적 밀리초 기록. 프롬프트·계정 정보는 시간 기록에 포함하지 않음.
- 실행 중 경과 초, 실행 기록 상세 시간. 기록은 탭 메모리에만 보관.
- 중간 생성 미리보기는 구현하지 않음. 확인되지 않은 프로토콜 이벤트를 사용하지 않음.

## 검증 상태
- 81/81 Node 테스트 통과. 지연된 turn 완료보다 이미지 전달이 먼저 발생하는 회귀 테스트 포함.
- 실제 계정 생성 및 웹과의 속도 비교 미실행. 모델 생성 시간 단축 수치 없음.
- 구현 자체 평가 8/10. 실제 계정 시간 분해와 브라우저 상호작용 재검증 필요.
- 설치 및 패키지 검증 결과는 배포 폴더의 릴리스 안내에 기록.
