# NodeCanvas v1.7.0 단순한 노드와 사용 설명서 위치 표시

승인 범위: 아이콘 축소·해당 아이콘 hover/focus만 설명 표시·매뉴얼 현재 위치 표시. 사용자 추가 요청으로 결과 노드를 완전히 제거하고 두 템플릿도 수정. 기존 브라우저 프로젝트 데이터는 삭제하지 않는다.
- [x] 결과 노드의 타입·메뉴·실행·파생 미리보기·템플릿·도움말 제거. 예전 결과 노드 JSON은 지원하지 않음.
- [x] 텍스트 → 생성 2개 노드, 이미지+편집 지시 → 편집 3개 노드 템플릿. 생성·편집 카드에서 바로 저장.
- [x] 포트 보이는 원 18px/클릭 영역 28px. 개별 포트 hover/focus만 안내, 노드 hover·선택·연결 상태는 전체 안내를 펼치지 않음.
- [x] 설명서 목차 현재 위치 색상·배경·표시선·aria-current. 스크롤·클릭·해시 진입·페이지 끝 처리.
- [x] 새 동작 회귀 검사와 실제 브라우저 템플릿·툴팁·저장·목차·모바일 검증.
- [x] 설치 파일·문서 4개·배포 폴더·ZIP 갱신, 이전 v1.6.0 보존.

노드 제거로 기존 결과 기능 검사 파일은 이번 새 버전에 복사하지 않고, 이전 v1.6.0 폴더에 보존한다. 저장·보안·연결 등의 기존 검사는 새 지원 타입으로 계속 검증한다. 공개 배포는 사용자가 진행.

최종 검사: 70/70. 공개 배포·실제 신규 PC·물리 터치·실계정 생성은 미검증.
