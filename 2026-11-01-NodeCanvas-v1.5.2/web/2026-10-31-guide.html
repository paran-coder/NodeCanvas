01 · 시작하기

무엇을 준비하면 되나요?

NodeCanvas는 브라우저에서 작업하고, Windows 연결 앱을 통해 내 ChatGPT 계정으로 이미지 생성을 요청하는 도구입니다.

  • Windows 10/11 x64 PC와 인터넷 연결
  • 이미지 생성 기능을 사용할 수 있는 ChatGPT 계정
  • 처음 한 번 설치하는 NodeCanvas 연결 앱
프로젝트 편집과 설명서 열람에는 로그인이 필요 없습니다. 실제 이미지 생성 가능 여부와 사용 한도는 계정·구독·Codex 버전에 따라 달라집니다.
02 · AI 연결

PC 연결과 계정 로그인은 달라요.

PC 연결은 작업실과 내 컴퓨터 사이의 통로를 여는 단계, 계정 로그인은 그 통로에서 사용할 내 ChatGPT 계정을 인증하는 단계입니다.

1

작업실과 내 PC 연결하기

작업실에서 AI 연결을 엽니다. 처음이면 설치 앱 다운로드로 받은 파일을 실행해 설치하세요. 이미 설치했다면 다시 설치할 필요가 없습니다.

PC 연결하기를 누르고, 브라우저가 물으면 앱 열기를 허용합니다. 연결 앱에서 작업실 주소를 확인합니다.

완료 표시: ✓ PC 연결 완료

이 표시는 PC 연결만 끝났다는 뜻입니다. 아직 계정 로그인 전일 수 있어요.

2

공식 페이지에서 내 계정 로그인하기

PC 연결 후 로그인 시작하기를 누릅니다. 이어서 나타나는 검은색 공식 페이지에서 로그인하기 ↗를 누르세요.

새로 열린 공식 페이지에서 직접 로그인합니다. 필요한 계정 선택과 인증을 완료하세요.

공식 페이지를 여는 것만으로 로그인이 끝나지는 않습니다. 해당 페이지 안에서 인증을 끝내야 합니다.
3

이 작업실로 돌아오기

인증을 끝낸 뒤 원래 작업실 탭으로 돌아오세요. 완료 여부를 자동으로 확인합니다.

완료 표시: ChatGPT 연결됨

이제 연결창을 닫고 이미지를 만들 수 있습니다. 바로 바뀌지 않으면 고급 연결의 상태 다시 확인을 누르세요.

‘링크 다시 받기’는 언제 누르나요?

공식 페이지가 열리지 않거나 링크가 만료됐을 때만 사용합니다. 이미 공식 페이지에서 로그인 중이라면 그대로 완료하세요. 새 링크를 받으면 앞서 열었던 로그인 요청이 바뀔 수 있습니다.

‘이 PC에서 로그인 유지’는 무엇인가요?

선택하면 연결 앱이 OS 자격 증명 저장소를 사용해 다음 실행에도 로그인을 유지하도록 합니다. 개인 PC에서만 선택하세요. 선택하지 않으면 임시 로그인으로 사용하며 연결 앱 종료 후 다시 로그인해야 합니다. 로그인 요청 중에는 선택을 바꿀 수 없습니다.

03 · 첫 이미지

노드 하나로 시작하세요.

  1. 프로젝트 목록에서 새 프로젝트를 만듭니다.
  2. 빈 캔버스를 우클릭하거나 ＋를 눌러 이미지 생성기를 추가합니다.
  3. 노드 안 프롬프트 칸에 원하는 장면을 적습니다.
  4. ChatGPT 연결됨을 확인하고 전체 실행을 누릅니다.
  5. 생성이 끝나면 노드에서 이미지를 확인하고 저장합니다.
프롬프트 예시

따뜻한 아침 햇빛이 드는 창가의 작은 꽃병. 흰 배경, 부드러운 그림자, 정사각형 제품 사진.

실행은 구독 사용 한도를 사용할 수 있습니다. 반복 실행하면 생성·편집 노드가 다시 실행될 수 있으니 필요한 작업만 실행하세요.
04 · 노드

각 노드는 무슨 일을 하나요?

노드 제목 옆 ?에서도 역할과 연결 예시를 볼 수 있습니다. 텍스트는 지시문, 이미지는 작업 재료입니다.

T

텍스트

원하는 장면·스타일·수정 지시를 적고 다른 노드로 전달합니다.

입력: 글 직접 입력
출력: 텍스트
↥

이미지 업로드

PC의 PNG·JPG·WebP를 가져옵니다. 카드를 짧게 클릭하면 선택창, 누른 채 끌면 노드 이동입니다.

입력: 내 이미지 파일
출력: 이미지
✦

이미지 생성기

지시문과 선택 사항인 참조 이미지를 바탕으로 새 이미지를 만듭니다. 노드 안에 바로 지시문을 적어도 됩니다.

입력: 텍스트 · 참조 이미지(선택)
출력: 새로 생성한 이미지
◈

이미지 편집기

연결된 이미지에서 바꿀 부분과 유지할 부분을 지시합니다. 편집할 이미지가 최소 한 장 필요합니다.

입력: 이미지 + 편집 지시문
출력: 편집한 이미지
▧

결과

연결된 최신 이미지를 자동으로 보여주고 저장합니다. 실행 버튼이 없으며 AI를 다시 실행하지 않습니다. 연결을 해제하면 미리보기가 비워집니다.

입력: 이미지
역할: 최종 결과 확인 · 저장

생성 카드에도 이미지가 있는데 결과 노드가 필요한가요?

결과 노드는 선택 사항입니다. 생성·편집 카드에서도 이미지 확인과 저장이 됩니다. 작업 흐름 끝에 최종 이미지만 따로 확인하고 싶을 때 결과 노드를 연결하세요. 연결·생성·업로드 직후 자동으로 갱신됩니다. 여러 입력이 있으면 연결 순서에서 처음 사용 가능한 이미지가 표시됩니다. 결과 노드를 통해 다음 노드로 이미지를 보낼 수도 있습니다.

텍스트→이미지 생성기→결과 · 선택 사항
이미지 업로드 + 텍스트→이미지 편집기→결과

노드 오른쪽 출력 포트를 잡고 다음 노드 왼쪽 입력 포트까지 끌어 연결합니다. 순환 연결과 호환되지 않는 연결은 만들 수 없습니다.

05 · 조작

클릭은 입력, 드래그는 이동.

노드 추가
빈 캔버스 우클릭 / ＋ / Space
노드 이동
카드 여백·이미지·제목 영역을 잡고 끌기. 입력칸은 편집용입니다.
연결선 만들기
출력 점 → 입력 점으로 드래그. 빈 곳에 놓으면 호환 노드를 고릅니다.
화면 이동
빈 캔버스를 끌거나 H로 이동 도구 선택. V는 선택 도구.
확대·축소
마우스 휠 또는 화면 아래 − / +. 전체 노드 보기는 맞춤 보기 버튼.
취소·삭제
Esc: 연결 취소 / Delete: 선택 노드 삭제
실행 취소·다시 실행
Ctrl+Z / Ctrl+Shift+Z 또는 Ctrl+Y. 입력칸에서는 글 편집 취소가 먼저 적용됩니다.
06 · 보관

자동 저장과 파일 백업을 구분하세요.

자동 저장은 현재 브라우저에 프로젝트를 보관합니다. 계정으로 다른 PC에 동기화되는 기능은 아닙니다. 브라우저 데이터 삭제 시 작업도 사라질 수 있습니다.

저장 ↗ 또는 Ctrl+S는 프로젝트를 JSON 파일로 내려받는 백업입니다. 이미지를 포함하며 현재 저장·가져오기 공통 제한은 200MB입니다. 프로젝트 목록의 가져오기로 백업을 다시 엽니다. 이미지 저장은 결과 이미지만 내려받습니다.

  • 프로젝트 목록에서 이름 변경, 복제, 휴지통 이동과 복원을 할 수 있습니다.
  • 영구 삭제는 휴지통에서만 합니다. 백업 후 ‘삭제’를 입력해 확인하면 되돌릴 수 없습니다.
  • 저장 실패 시 저장 재시도를 누릅니다. 다른 탭에서 수정해 충돌했다면 현재 작업을 JSON으로 백업하고 새로고침하세요.
07 · 문제 해결

여기서 막혔나요?

‘PC 연결 완료 · 로그인해 주세요’가 보여요.

PC 연결만 완료됐습니다. 2번에서 로그인 시작하기 → 공식 페이지에서 로그인하기를 누르고 계정 인증까지 완료하세요.

로그인했는데 작업실이 대기 중이에요.

원래 작업실 탭으로 돌아온 뒤 잠시 기다리세요. 고급 연결 → 상태 다시 확인을 눌러 확인합니다. 공식 페이지에서 인증이 끝났는지도 확인하세요. 링크 만료 안내가 있으면 링크를 다시 받아 최신 페이지에서 진행합니다.

‘7330 포트를 사용 중’이라고 나와요.

이전에 실행한 연결 앱이나 개발용 서버가 남아 있을 수 있습니다. 기존 연결 앱을 종료한 뒤 PC 연결하기를 다시 누르세요. 다른 프로그램이 해당 포트를 사용하는 경우에는 그 프로그램을 확인해야 합니다. 재설치만으로 포트 충돌이 해결되지는 않습니다.

연결하기를 눌러도 앱이 열리지 않아요.

연결 앱을 먼저 설치했는지 확인하고 브라우저의 ‘앱 열기’ 요청을 허용하세요. 연결 앱에서 작업실 주소가 현재 사이트와 같은지 확인합니다. 자동 연결이 안 되면 고급 연결의 연결 코드 입력을 사용합니다. 브라우저가 로컬 네트워크 권한을 물으면 연결 앱 접근을 허용하세요.

노드가 움직이지 않거나 연결이 안 돼요.

선택 도구(V)인지 확인하고 입력칸·버튼 대신 카드 여백이나 이미지를 잡으세요. 연결은 출력 점에서 입력 점으로 끕니다. 입력칸은 글 편집용이며, 모든 포트 조합이 연결되는 것은 아닙니다.

이미지 생성이 실패했어요.

ChatGPT 연결됨 상태, 인터넷 연결, 오류 안내와 계정 사용 한도를 확인하세요. 이미지 편집에는 입력 이미지가 필요합니다. 결과 노드만 추가해도 새 이미지가 생성되지는 않습니다.

08 · 연결 정보

무엇이 어디에 보관되나요?

프로젝트는 브라우저에 저장됩니다. ChatGPT 인증 토큰은 웹이나 Vercel에 저장하지 않으며 연결 앱이 처리합니다. 이미지 생성을 실행하면 입력 지시문과 필요한 이미지가 연결 앱을 통해 AI 서비스로 전달됩니다.

‘이 브라우저에서 PC 연결 기억하기’는 작업실과 연결 앱 사이의 연결 정보를 기억하는 설정입니다. ‘이 PC에서 로그인 유지’는 ChatGPT 계정 인증을 유지하는 설정으로 서로 다릅니다.

마지막 작업실 연결 탭을 닫으면 약 90초 뒤 연결 앱이 종료됩니다. 이 설명서 탭은 AI 연결을 유지하지 않습니다. 설명서만 열어둔 채 작업실을 모두 닫으면 다시 연결해야 할 수 있습니다.
