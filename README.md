# NodeCanvas v1.17.0

이미지 노드를 연결해 생성·편집하는 웹 작업실입니다.

## 이번 버전

- 생성 카드에서 ×1~×4를 선택합니다. ×4로 실행하면 현재 노드와 새 노드 3개에 같은 프롬프트·비율·참조·스킬을 적용하고, 한 장씩 순서대로 생성합니다. 새 노드는 장수가 ×1로 시작합니다.
- 비율과 장수는 작은 메뉴로 선택합니다. 방향키, Home/End, Enter/Space와 Escape로 조작할 수 있습니다.
- 프롬프트 입력란의 안쪽 포커스 선을 제거하고 카드 바깥 테두리로 포커스를 표시합니다.
- 프롬프트 위의 ＋로 참조 이미지를 고르거나 @이름을 입력합니다. 선택된 이미지는 썸네일로 표시됩니다. 썸네일의 ×를 누르면 연결선과 해당 @참조가 함께 정리됩니다.

장수는 각 생성 카드의 실행 버튼에 적용합니다. 상단 전체 실행은 현재 그래프를 한 번 실행합니다. 대기열은 실행 중 포함 최대 8개입니다. 여러 장이 함께 사용하는 참조 생성 노드에 아직 완성 이미지가 없으면, 그 참조를 먼저 생성한 뒤 다시 실행합니다.

## 로컬 실행

Node.js 22 이상이 설치된 PowerShell에서 저장소 루트로 이동해 실행합니다.

    node ./2026-11-01-NodeCanvas-v1.13.0/connector/2026-10-31-server.mjs

브라우저에서 http://127.0.0.1:7330/ 을 엽니다. 실제 AI 생성에는 로컬 연결 앱과 Codex 런타임·계정 로그인이 필요합니다.

## GitHub와 Vercel

이 폴더의 내용물을 저장소 루트에 올립니다. `vercel.json`의 정적 배포 경로는 `2026-11-01-NodeCanvas-v1.13.0/web`입니다. 내부 폴더명은 기존 경로를 따르고 웹 버전은 v1.17.0입니다.

동봉 설치 EXE와 서명 업데이트 자료는 기존 v1.13.0 계열입니다. v1.17.0 웹 작업본은 위 명령으로 실행할 수 있습니다.
