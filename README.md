# NodeCanvas v1.18.1

## 이번 수정

- 캔버스에서 여러 노드를 선택한 후 Delete를 누르면 확인 한 번으로 선택한 노드와 연결이 함께 삭제됩니다. Ctrl+Z 한 번으로 복구할 수 있습니다. 실행 또는 대기 중인 노드가 선택에 포함돼 있으면 해당 작업을 완료하거나 취소한 뒤 삭제할 수 있습니다.
- 하단 작업 목록 바깥을 마우스로 클릭하면 목록을 닫고 버튼의 포커스를 해제합니다. Tab 키로 버튼에 이동하면 포커스 테두리를 표시합니다.
- 동시 생성은 기존 연결 앱 v1.13.1을 사용합니다. 이미 설치했다면 웹만 갱신하면 됩니다.

## 이미지 생성

이미지 생성 카드에서 ×1~×10을 고릅니다. **순차**가 기본값이며, **동시**를 선택하면 같은 프롬프트·비율·참조·스킬로 최대 10개 작업을 함께 시작합니다. 기존 카드와 자동으로 생긴 카드에 각 결과가 저장됩니다. 하단 작업 목록에서 개별 작업을 취소할 수 있습니다. 장수 설정은 해당 카드의 실행 버튼에 적용됩니다.

## 연결 앱

동시 생성은 연결 앱 v1.13.1이 필요합니다. 작업실의 **AI 연결 → 설치 앱 다운로드**에서 새 설치 파일을 받아 실행하고 **PC 연결하기**를 누릅니다. 이어서 ChatGPT 연결을 확인합니다. 이번 v1.13.1은 수동 설치로 제공됩니다.

## 로컬 실행

저장소 루트에서 다음 명령을 실행하고 브라우저에서 [작업실](http://127.0.0.1:7330/)을 엽니다.

    node ./2026-11-01-NodeCanvas-v1.13.0/connector/2026-10-31-server.mjs

## 검증 범위

독립 시험판에서 실계정 10장 동시 생성이 완료됐습니다. 통합판은 Chrome과 로컬 브리지의 모의 생성으로 순차 4장, 동시 10장 저장, 별도 동시 실행에서 생성 중 한 건만 취소한 뒤 나머지 9장 저장, 새로고침 후 재열기를 확인했습니다. 통합판 실계정 생성과 새 PC 설치는 확인 예정입니다.
