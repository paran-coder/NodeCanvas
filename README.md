# NodeCanvas v1.16.0

이미지 노드를 `@이름`으로 연결하고, 이미지 카드에서 바로 프롬프트를 편집하는 웹 작업실입니다.

## 로컬 실행

Node.js 22 이상이 설치된 Windows PowerShell에서 저장소 루트로 이동해 다음을 실행합니다.

    node ./2026-11-01-NodeCanvas-v1.13.0/connector/2026-10-31-server.mjs

브라우저에서 http://127.0.0.1:7330/ 을 엽니다. 실제 AI 생성에는 로컬 Codex 런타임과 계정 로그인이 필요합니다.

## GitHub와 Vercel

이 폴더의 내용물을 저장소 루트에 올립니다. `vercel.json`은 `2026-11-01-NodeCanvas-v1.13.0/web`을 정적 배포합니다. 내부 폴더명은 기존 배포 경로를 따르며 웹 화면 버전은 v1.16.0입니다.

웹에 포함한 설치 EXE와 서명 업데이트 자료는 기존 v1.13.0 배포본입니다. v1.16.0 웹 화면을 로컬에서 확인하려면 위 명령을 사용합니다.
