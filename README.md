# NodeCanvas v1.19.2

## 전체 보기와 Space 드래그

마우스로 전체 보기나 배율 버튼을 누르면 버튼 포커스가 해제됩니다. 그 뒤 Space를 누르고 드래그해도 배율과 이동 위치가 유지됩니다. Tab으로 버튼에 이동한 경우 Space로 실행할 수 있습니다.

연결 앱이 제공하는 로컬 작업실을 쓴다면 Windows 트레이에서 기존 연결 앱을 종료하고 연결 앱 v1.14.1 설치 파일을 실행합니다. 연결 앱을 다시 열고 작업실의 버전 표시가 v1.19.2인지 확인합니다.

## 이미지 생성
- 장면마다 액션·포즈·구도가 달라야 한다면 프롬프트에 명시합니다. 예를 들어 “같은 캐릭터로 각각 다른 액션 장면”이라고 적고 ×4 또는 ×10을 고릅니다.
- 코덱스가 장면을 기획하고 카드마다 하나씩 배정합니다. 참조 이미지와 공통 프롬프트를 각 생성 요청에 적용합니다. 여러 장을 함께 생성하려면 카드에서 동시를 선택하세요.
- 같은 장면의 후보는 장수만 고르고 기존 방식으로 생성합니다.
- 새 기능을 사용하려면 AI 연결에서 v1.14.1 설치 파일을 받아 실행하고 PC 연결하기를 누릅니다. ChatGPT 연결 상태를 확인한 뒤 생성합니다.

저장소 루트에서 로컬로 실행하려면 다음 명령을 사용합니다.

    node ./2026-11-01-NodeCanvas-v1.13.0/connector/2026-10-31-server.mjs

[로컬 작업실](http://127.0.0.1:7330/)을 엽니다.

이 폴더의 내용물을 저장소 루트에 올립니다. Vercel 정적 경로는 2026-11-01-NodeCanvas-v1.13.0/web입니다.

## 검증

Chrome과 모의 브리지로 장면 4개·10개를 한 장씩 배정하고, 기존 참조와 비율을 전달하는 것을 확인했습니다. 기획 실패 시 생성 요청을 보내지 않습니다. 실제 계정의 기획과 이미지 생성은 연결 앱 설치 후 확인할 수 있습니다.
