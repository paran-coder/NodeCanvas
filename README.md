# NodeCanvas v1.13.0 — 공통 스킬 노드

우클릭 메뉴에서 ‘스킬’로 들어가 목록의 HairLock을 선택합니다. 전체 메뉴에는 공통 스킬 진입점 하나만 표시하며, 각 스킬은 같은 skill 유형의 노드로 추가됩니다. 현재 실제 등록 스킬은 HairLock 하나입니다. 목록/선택 데이터는 공통 레지스트리에서 관리해 확장 기반을 마련했습니다.

노드에는 선택한 이름과 짧은 설명만 표시하고 노드/메뉴/포트에 범용 퍼즐 SVG 아이콘을 사용합니다. 원문 보기와 파일 업로드 UI는 없습니다. 원문 자체는 변경하지 않고 실행 시 전체 지침을 전달합니다.

기존 이미지와 스킬을 다음 생성·편집 노드의 각 입력에 연결하고 그 노드 안 실행 버튼을 누릅니다. 완성된 이전 AI 이미지와 지시는 재사용하고 새 결과는 다음 노드에 저장합니다. 전체 실행은 전체 워크플로를 다시 만들 수 있습니다. HairLock은 원본 이미지가 필수이며 노드 하나에 스킬 하나, 같은 스킬 노드 공유를 지원합니다.

## 배포
이 폴더 전체를 저장소 루트에 반영하세요. vercel.json은 2026-11-01-NodeCanvas-v1.13.0/web을 사용합니다. 설치 EXE와 서명 매니페스트를 함께 배포합니다. 공개 업로드/배포 및 PC 설치는 여기서 실행하지 않았습니다.

기존 v1.12.0 HairLock 프로젝트는 같은 스킬 ID/연결 형식을 유지합니다. 더 이전 버전으로 돌아가려면 업데이트 전 JSON도 보관하세요. 생성 노드의 스킬 연결은 v1.11.0 이하 미지원이며 v1.10.0 이하는 스킬 노드도 미지원입니다.

## 검증
103/103 Node 회귀 테스트. 실제 Chromium에서 목록 진입/스킬 선택/간결한 노드/원문 보기 없음/퍼즐 아이콘/연결·해제·저장·재접속·PC/모바일 검증 PASS. AI 요청은 모의이며 실제 인물 품질은 미검증입니다. 기존 이미지 보존/새 결과 위치/이미지 누락 차단도 통과했습니다. 설치 self-test, 이전 공개키로 새 릴리스 서명 검증과 ZIP 무결성 확인 PASS. 자체 평가 8.5/10. 실제 PC/HTTPS 전체 업데이트 수용 테스트는 미검증입니다.

## 서명 및 원문
HairLock v1.0.1 원문은 sample ZIP과 바이트가 동일합니다. 자동 후보 비교/품질 검수/재시도는 제공하지 않습니다. 스킬+지시는 16,000자 제한이며 임의로 줄이지 않습니다.
비밀키는 ZIP에서 제외했습니다. 원본 루트 .runtime/2026-11-01-update-signing/private.pem은 보존·별도 백업하세요. 다음 릴리스에도 같은 키와 공개키를 사용해야 합니다. RSA 업데이트 서명과 Windows Authenticode 서명은 별개입니다.
