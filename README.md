# NodeCanvas v1.2.0

한국어 노드 기반 이미지 작업실. 정적 웹 편집기와 사용자 PC의 Codex를 연결하는 로컬 앱으로 구성됩니다. 서버에 ChatGPT 로그인 정보를 올리지 않습니다.

## 실행

Node.js 22 이상과 Codex CLI가 필요합니다. PowerShell에서:

```powershell
& '.\2026-10-31-NodeCanvas-v1.2.0\connector\2026-10-31-start-nodecanvas.ps1'
```

브라우저에서 `http://127.0.0.1:7330`을 열고 터미널의 페어링 코드를 AI 연결 창에 입력합니다. 자세한 절차는 `User manual.md` 참고.

## 확인

```powershell
node --test 2026-10-31-NodeCanvas-v1.2.0/tests/*.test.mjs
```

## 배포

프로젝트 루트의 `vercel.json`이 정적 웹앱 경로를 지정합니다. Vercel에 루트를 가져오고 Framework를 Other로 선택합니다. 사용자별 연결 앱은 PC에서 별도로 실행해야 합니다. 배포된 웹의 정확한 origin을 실행 스크립트의 `-SiteUrl`로 지정합니다.

이 릴리스는 개인 로컬 연결용입니다. Codex app-server 인증의 상업·호스팅 서비스 제한 및 Sign in with ChatGPT 도입 조건을 검토하기 전, 공개 구독 연결 서비스로 제공하지 마세요. 실제 구독 생성·신규 PC 설치·공개 배포 검증 여부는 날짜별 검증 보고서에 명시합니다.

원본 `sample`은 변경하지 않습니다. 앱 데이터·인증·생성물은 `.runtime`에 저장되며 Git에서 제외됩니다.

v1.2.0은 한글 Magnific 참고 화면의 미디어 중심 구조를 반영했습니다. 카드 바깥 제목, 정사각형 이미지, 하단 직접 프롬프트, 선택 시 비율·실행 설정, 왼쪽 선택/화면 이동 도구, 한국어 분류 검색을 제공합니다. 드래그 연결과 빈 곳 드롭 자동 연결도 유지합니다. 이전 v1.0.0/v1.1.0 폴더와 ZIP은 보존하고 프로젝트 JSON은 version 1.0.0 형식을 유지합니다.
