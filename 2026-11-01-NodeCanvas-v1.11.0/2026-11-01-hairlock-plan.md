# NodeCanvas v1.11.0 — HairLock

사용자 승인 범위: HairLock 원문을 변경하지 않고 이미지 편집 스킬로 적용. 기존 v1.9.0 보존.

1. 원본 ZIP의 SKILL.md를 바이트 그대로 추출하고 해시를 고정. 기본 제공 및 동일 원본 단일 MD 업로드 지원.
2. 편집 노드에 스킬 선택·해제·원문 보기 추가. 상태는 프로젝트/JSON/undo에 보존. 다른 노드 유형 적용 거부.
3. 전체 원문과 사용자 지시를 함께 전달. 원본 이미지와 지시 누락·16,000자 합계 초과를 사전 거부. 임의 요약/절단 금지.
4. 자동 검수/재시도는 구현하지 않으며 원문의 지침과 실제 앱 지원 범위를 구별.
5. 원문 동일성·실행 입력·저장/복구·UI 테스트, 설치 앱 빌드·동일 키 서명·배포 패키지 검증.

새 폴더의 파일만 변경하며 기존 루트 4개 문서와 이전 배포본은 보존. 실제 이미지 생성은 검증하지 않음.
