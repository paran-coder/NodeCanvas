# NodeCanvas v1.11.0 更新計画 / 업데이트 계획

승인: 자동 확인·다운로드 후 지금 적용 버튼 방식. 기존 v1.8.2 보존.

1. 서명된 업데이트 매니페스트 검증, 고정 HTTPS 배포 주소, 해시·크기 검증, 다운그레이드 거부 테스트.
2. Native 설치에 side-by-side 업데이트 및 재시작, 레지스트리 복구, 시작 확인 실패 시 이전 버전 복귀. 사용자 데이터 경로 유지.
3. API 페어링·origin 검증 재사용, 생성/로그인/갱신 간 상호 배제. 웹에서 준비 상태 표시 및 적용 후 새 challenge로 재연결.
4. 테스트·설치 자체 검증·서명·배포 ZIP 검증. 공개 배포와 실제 설치는 수행하지 않음.

매니페스트 서명은 RSA-SHA256, 공개키는 연결 앱에 포함. 비밀키는 작업 폴더 .runtime 하위만 보관하고 배포 제외.
최초 v1.11.0 수동 설치 필요. 임시 로그인은 재시작 시 해제, 로그인 유지 설정/브라우저 프로젝트는 보존.
실제 업데이트는 미래 버전 매니페스트와 설치 앱을 함께 배포해야 시작됨.
